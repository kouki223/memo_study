# ソフトウェアはトウモロコシの夢を見るか

米国のトウモロコシは生産性が7倍に向上した結果、人間が直接消費する割合は数%に縮小し、余剰は畜産や燃料など新たな用途に流れました。いまAIによりコード生成コストが下がる中、ソフトウェアにも同様の構造変化が起きつつあります。人間向けアプリ・ソフトウェアの比率は縮小し、AIが消費する「揮発性ソフトウェア」が増える世界で、エンジニアの役割はどう変わるのか。何を作り何を捨てるかという判断は人間に残り続け、偶有的複雑さはAIが吸収していきます。本セッションでは、この転換を農業の構造と重ねて捉え直します。

ジョブクラフティングという概念

いずれ、いまやっている仕事も名前がなくても後追いで名前がついてくる
=> 重要な事は名前を追いかけるのではなく、やっている事に後追いで名前がつけられるというイメージ
